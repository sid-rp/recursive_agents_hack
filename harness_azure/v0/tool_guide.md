Browser tools: observe() refreshes the screen; click(element), type_text(element, text, submit) and scroll(direction,
element) act on the numbered elements of the CURRENT SCREEN; press_key(key); go_to_url(url) for Azure URLs;
read_page() returns the visible text; wait(seconds) for slow blades. Numbers change after every action: always use
the latest screen. ask_human(question) asks the operator.
